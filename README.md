## 📖 О проекте

**Techturient** создан для устранения рутинных бумажных операций и минимизации человеческого фактора во время приёмной кампании:
* Исключает ошибки ручного подсчёта среднего балла аттестата.
* Защищает от непреднамеренного дублирования абитуриентов по паспортным данным.
* Автоматизирует взаимодействие с резервом договорников (альтернативные приоритеты).
* Генерирует официальные бланки заявлений Word (.docx), ведомости в Excel (.xlsx) и печатные формы PDF в один клик прямо в браузере.

## ✨ Ключевой функционал

* **Интерактивный 8-шаговый мастер регистрации поступающего**:
  * Персональные данные, маски для телефона и СНИЛС.
  * Паспортные данные РФ и адресные сведения с опцией автокопирования прописки.
  * Сведения о родителях (законных представителях) и воинский учёт.
  * Калькулятор оценок с автоматическим расчётом среднего балла с точностью до сотых.
  * Выбор основной образовательной программы (ППССЗ / ППКРС, Бюджет / Договор).
  * Поддержка 2-го и 3-го приоритетов специальностей для коммерческого резерва.
  * Учёт льгот и особого права (СВО, дети-сироты, целевое обучение, инвалидность).
* **Конкурсные динамические списки**:
  * Сквозной поиск по ФИО, СНИЛС или индивидуальному шифру.
  * Фильтры по специальностям, форме финансирования и факту сдачи оригинала аттестата.
  * Автоматическое ранжирование: средний балл $\rightarrow$ оригинал аттестата $\rightarrow$ дата подачи.
* **Модуль коммерческого набора («Лист обзвона»)**:
  * Единый реестр абитуриентов, согласных на платное обучение или имеющих 2/3 приоритеты.
  * Быстрое копирование номеров телефонов.
  * Статусы разговора («Согласен на договор», «В раздумьях», «Отказ», «Не дозвонились»).
  * Кнопка **пакетного сохранения** всех изменений списка разом.
* **Генератор документов и отчётов**:
  * Заполнение Word-бланков (.docx) на базе настраиваемых шаблонов.
  * Экспорт конкурсных рейтингов в форматированные таблицы Excel (.xlsx).
  * Генерация стандартизированных печатных ведомостей в PDF.
* **Публичный рейтинг**:
  * Открытый доступ для поступающих без авторизации.
  * Защита персональных данных (ФИО скрыты, поиск по анонимному коду `REG-2026-XXXX` или СНИЛС).

## 🗄 Структура базы данных (Cloud Firestore)

* `campaigns` — периоды набора (например, «Приёмная кампания 2026»).
* `applicants` — личные дела поступающих:
  * Персональные реквизиты, паспорт, СНИЛС, адреса.
  * Данные аттестата, оценки (`threes`, `fours`, `fives`), средний балл `averageScore`.
  * Приоритеты: `specialty`, `alternativeSpecialties` (массив альтернативных направлений).
  * Статусы обзвона: `commercialInterest`, `callStatus`, `callNote`, `callUpdatedAt`.
  * Вложенные реестры: `documents`, `relatives`, `militaryRecord`.
* `documentTemplates` — бинарные шаблоны бланков Microsoft Word (.docx) в формате Base64.
* `audit_logs` — журнал действий операторов системы (протоколирование создания, редактирования, смены специальности и экспорта).

## 📋 Инструкция пользователя и регламент работы

### 1. Выбор и создание приёмной кампании
1. При входе в систему откроется стартовый экран выбора кампании.
2. Выберите действующую приёмную кампанию (например, «Приёмная кампания 2026») либо нажмите **«Создать кампанию»**, чтобы открыть новый период набора.
3. В шапке приложения всегда отображается текущая активная кампания и индикатор статуса соединения.

### 2. Регистрация абитуриента (8-шаговый мастер)
Для добавления абитуриента нажмите кнопку **«Зарегистрировать абитуриента»**:
* **Шаг 1. Персональные данные**: укажите ФИО, дату рождения, пол, телефон и СНИЛС.
* **Шаг 2. Паспорт**: введите 4 цифры серии, 6 цифр номера, орган выдачи, дату и код подразделения.
* **Шаг 3. Адреса**: укажите прописку и фактическое место жительства (доступна галочка для мгновенного дублирования адреса).
* **Шаг 4. Семья и военкомат**: внесите контакты родителей и сведения о постановке на воинский учёт (для юношей).
* **Шаг 5. Аттестат**: выберите вид сдачи документа (Оригинал / Копия) и укажите количество пятёрок, четвёрок и троек — средний балл рассчитается автоматически.
* **Шаг 6. Направление и резерв**: выберите основную специальность. Включите чекбокс «Рассматривать платное обучение», чтобы открыть выбор 2-го и 3-го приоритетов специальностей.
* **Шаг 7. Особые права / Льготы**: выберите льготную категорию (при наличии) и внесите реквизиты документа.
* **Шаг 8. Завершение и печать**: проверьте сводные данные, получите уникальный шифр (`REG-2026-XXXX`) и скачайте предзаполненное заявление Word (.docx).

> 💡 **Защита от дубликатов**: При повторной попытке зарегистрировать человека с существующей серией и номером паспорта система предложит обновить существующее дело вместо создания дублирующей записи.

### 3. Конкурсный дашборд и фильтрация
* **Сводные метрики**: блок виджетов показывает общее количество заявлений, поданные оригиналы, копии и распределение бюджет/договор.
* **Фильтры**: можно мгновенно отфильтровать список по образовательной программе, типу подготовки (ППССЗ / ППКРС) или наличию оригинала.
* **Действия с абитуриентом**: прямо из таблицы доступны просмотр личного дела, смена специальности (`EditSpecialtyModal`), печать согласий и удаление.

### 4. Лист обзвона и работа с платным резервом
1. Нажмите кнопку **«Лист обзвона»** на главном дашборде.
2. В таблице отобразятся абитуриенты, готовые к платному обучению, с указанием их 2-го и 3-го приоритетов.
3. Используйте кнопку копирования телефона для быстрого набора номера.
4. Проставьте статус беседы (`Согласен на договор`, `В раздумьях`, `Отказ`, `Не дозвонились`) и примечание.
5. Нажмите **«Сохранить весь список сразу»**, чтобы пакетно зафиксировать результаты в базе данных без необходимости сохранять каждого абитуриента по отдельности.
6. При необходимости экспортируйте ведомость звонков в Excel или распечатайте PDF-бланк.

### 5. Публичные рейтинговые списки
* Доступны по кнопке **«Публичный рейтинг»** или по прямому маршруту `/rating`.
* Абитуриенты ранжируются в порядке убывания среднего балла аттестата. Приоритет отдаётся поступающим, сдавшим оригинал документа.
* Персональные данные анонимизированы: абитуриент находит себя в списке по коду (`REG-2026-XXXX`) или номеру СНИЛС.

### 6. Формирование отчётности (DOCX, Excel, PDF)
* **Word (.docx)**: генерирует индивидуальное заявление поступающего со всеми персональными реквизитами.
* **Excel (.xlsx)**: формирует ведомость с сортировкой по баллам, контактными телефонами и отметками об оригинале.
* **PDF**: формирует официальный постраничный протокол с шапкой учебного заведения, готовый к выгрузке на информационный стенд.

## 💻 Установка и локальный запуск

### Требования:
* Node.js v18.0+ (рекомендуется v20 LTS)
* Пакетный менеджер npm

### Пошаговая инструкция:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-username/techturient.git
   cd techturient
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Настройте переменные окружения**:
   Создайте файл `.env` в корне проекта (по образцу `.env.example`):
   ```env
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   VITE_FIREBASE_APP_ID=your_app_id
   ```

4. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу: `http://localhost:3000`

5. **Сборка для production**:
   ```bash
   npm run build
   ```

## 🔒 Безопасность и защита персональных данных

* **Соблюдение ФЗ-152 «О персональных данных»**: в открытых рейтинговых списках ФИО и паспорта скрыты, идентификация ведётся по анонимным регистрационным кодам и СНИЛС.
* **Firestore Security Rules**: чтение открытых рейтингов разрешено публично, а запись и редактирование личных дел строго ограничены авторизованными операторами.
* **XSS и инъекции**: интерфейс на React автоматически санитизирует выводимые данные, а NoSQL-запросы к Firestore типизированы и исключают возможность внедрения вредоносного кода.
* **Аудит**: все действия пользователей протоколируются в отдельной коллекции `audit_logs` с указанием времени и совершённой операции.
